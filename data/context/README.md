# Camadas de contexto

Estas camadas são preservadas para interpretar cobertura, qualidade e distribuição do conhecimento geocientífico. **Não entram automaticamente no motor PAG ETR como favorabilidade.**

Incluem geoquímica, petrografia, afloramentos, geocronologia, cobertura aerogeofísica, escalas de mapeamento, inventário geocientífico e IPG. O uso de cada uma deve respeitar a matriz de rastreabilidade em `audit/PAG_ETR_matriz_rastreabilidade_camadas.xlsx`.
