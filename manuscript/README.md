# Manuscrito EarthArXiv

Este diretório integra a estrutura oficial fornecida no pacote `eartharxiv-main.zip` com o manuscrito PAG ETR.

- `pag_etr_eartharxiv.tex` contém a fonte de trabalho.
- `figures` contém cópias das figuras científicas já existentes no pacote.
- `eartharxiv-template` preserva a distribuição de template recebida sem substituir os arquivos científicos do PAG ETR.
- `manuscript_portuguese.md` preserva o manuscrito mestre em português.

O resumo e as seções ainda não redigidas permanecem explicitamente marcados como conteúdo em elaboração. Nenhum resultado adicional foi inferido.
