Estados N0 a N4

← Voltar ao PAG ETR

N0 · Não avaliável

Evidência insuficiente para testar adequadamente o modelo. N0 não significa baixo potencial mineral.

N1 · Modelo aberto

O contexto permite manter a hipótese geológica aberta, sem demonstrar mineralização.

N2 · Justifica investigação geoquímica

Os requisitos definidos justificam aquisição dirigida de evidência.

N3 · Evidência local compatível

Existe evidência local compatível com o modelo, sem inferir depósito, recurso, reserva ou viabilidade.

N4 · Contradito localmente

Uma condição necessária possui contradição verificada para aquele modelo.

Regra central
SEM_DADO não é AUSENTE_VERIFICADO. UNKNOWN nunca é convertido automaticamente em FALSE.
